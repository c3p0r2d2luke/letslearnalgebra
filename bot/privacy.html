1.Scope

This Privacy Policy explains what data [Service/App Name] ("we", "us") collects through its Discord bot and companion app (together, the "Service"), and how that data is used. It applies to admins who install the Bot, users who sign in with Discord, and — where the Bot is installed in a server — the members of that server whose activity is synced.

2.Data We Collect

CategoryExamplesSource
Account data Discord user ID, username, discriminator/tag, avatar, email (if requested at login) Discord OAuth, when you sign in
Server structure Server ID/name, channel list and settings, role list, permissions, hierarchy Discord API, once the Bot is installed
Member data Member list, nicknames, role assignments, join dates Discord API, via Server Members Intent

We only receive Discord data covered by the permissions and intents granted when an admin installs the Bot (View Channels, Manage Channels, Manage Roles, Server Members Intent) and, for message relay, Send Messages, Read Message History, Embed Links, and Attach Files. We do not receive data from Discord servers or channels the Bot has not been added to.

3.How We Use Data

We do not use your data to serve third-party advertising, and we do not sell personal data.
